# MediaPlayer

## 專案簡介

本程式是一個簡易的影片播放器，使用者可以透過「瀏覽」按鈕選擇本機影片檔案。影片載入後，使用者可以選擇想要的播放速度，例如慢動作、正常速度或快轉，接著按下播放按鈕開始播放影片，以及可以選擇是否暫停或停止影片。

---

## 主要功能

### 1. 瀏覽影片檔案

使用者可以按下「瀏覽」按鈕，開啟檔案選擇視窗，並選擇要播放的影片檔案。

---

### 2. 播放影片

選擇影片並設定播放速度後，使用者可以按下「播放」按鈕開始播放影片。

播放時，程式會依照使用者選擇的速度進行播放，例如：

- 慢動作：0.5x
- 正常速度：1x
- 快轉：2x

---

### 3. 暫停影片

影片播放中可以按下「暫停」按鈕，讓影片暫停播放。

暫停後，使用者可以再次按下「播放」按鈕，繼續播放影片。

---

### 4. 停止影片

使用者可以按下「停止」按鈕停止影片播放。

停止後，影片會回到起始位置，並重新讓使用者選擇播放速度。

---

### 5. 影片速度控制

本播放器提供三種影片播放速度：

| 按鈕 | 播放速度 | 說明 |
|---|---|---|
| 慢動作 | 0.5x | 影片以較慢速度播放 |
| 正常速度 | 1x | 影片以正常速度播放 |
| 快轉 | 2x | 影片以較快速度播放 |

使用者必須先選擇播放速度，播放按鈕才會啟用。

---

### 6. 播放結束自動重置

當影片播放到最後時，程式會自動偵測影片播放結束狀態，並將播放器回復到初始載入狀態。

---

## 操作流程

1. 開啟程式。
2. 按下「瀏覽」按鈕。
3. 選擇要播放的影片檔案。
4. 選擇影片播放速度：
   - 慢動作 0.5x
   - 正常速度 1x
   - 快轉 2x
5. 按下「播放」開始播放影片。
6. 播放中可以選擇：
   - 按下「暫停」暫停影片
   - 按下「停止」停止影片並回到起始狀態
7. 影片播放結束後，播放器會自動回到可重新選擇速度的狀態。
